# Day 5: Introduction to Bash Scripting

## Objective
Automate routine Linux tasks using Bash scripts, variables, conditions,
loops, and command-line arguments.

## Scripts

| Script | Purpose |
|---|---|
| `system_report.sh` | Reports hostname, date, uptime, memory, and disk usage |
| `disk_alert.sh` | Warns when root filesystem usage reaches 80% |
| `bulk_check.sh` | Checks whether specified scripts exist |
| `script_inventory.sh` | Lists shell scripts and their file details |
| `validate_scripts.sh` | Checks Bash syntax using `bash -n` |
| `file_info.sh` | Displays information about a file supplied as an argument |

## Key Concepts
- Variables and command substitution
- Conditional statements using `if`, `else`, and `fi`
- Loops using `for`
- File permissions and script execution
- Bash syntax validation
- Positional arguments such as `$1`
- Automating repetitive and bulk operations

## Environment
- Ubuntu Linux
- Bash
- Virtual machine: VirtualBox
